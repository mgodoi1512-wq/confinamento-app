1. Extraia em uma NOVA pasta. Mantenha o projeto original como backup.
2. Copie do projeto anterior somente seu .git e seu .env LOCAIS para a nova pasta. Preserve separadamente eventuais chaves e configurações privadas de assinatura Android. Nenhum desses arquivos vai no pacote.
3. Na nova pasta, use Node 22.12+ e execute: npm ci; depois npm run build e npm run test:all (um comando por vez).
4. Leia README.md e docs/REVISAO-2026-10-24.md antes de publicar. A lista de remoções está em docs/ARQUIVOS-REMOVIDOS.txt.
5. Revise git status. O .gitignore protege arquivos gerados e privados. Se arquivos ignorados já estavam versionados, execute no PowerShell: .\scripts\desversionar-gerados.ps1 . O script não apaga arquivos do disco nem faz commit.
6. Depois de conferir: git add .; git diff --cached --stat; git commit -m "Revisa seguranca e limpa arquivos gerados"; git push origin main (um comando por vez).
